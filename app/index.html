jim-p25

HackRF One bench radio. Experimental stacks: P25 Phase 1 and narrowband FM. Transmit is the 1011 Hz P25 test tone or analog NBFM. These fields stay on this computer.

Transmit turns the test tone on and leaves it on. Stop turns it off. The RF amplifier stays off. Use a frequency you are allowed to transmit on. Keep the radios close together, or put a dummy load on the HackRF.

Receive and Transmit each latch on. Stop is the only button that turns them off.

Help

Channel

This panel is a HackRF One bench radio. Listen mode picks an experimental stack. P25 Phase 1 is one conventional C4FM voice channel, 12.5 kHz, FDMA, a clear group call, algorithm ID 80 hex, key ID 0. Narrowband FM is the analog stack on the same board. Phase 2 TDMA, trunking, scanning, and encryption keys stay off this bench. A radio with encryption off can decode the P25 test tone with its own IMBE decoder.

Receive

Receive latches listening on. A second click does not turn it off, which avoids stopping it during the few seconds GNU Radio takes to start. Stop is the off switch. Transmit latches the same way, and it turns receive off while the tone is on.

Receive audio is an RTC-style WebSocket, the reverse of the microphone path: GNU Radio UDP → /ws/pcm → AudioWorklet. No ALSA. P25 uses OP25 IMBE on 23456. FM uses analog.nbfm_rx UDP on 23458. Wide 25 kHz if you only hear a tail beep. Squelch 0.

The local oscillator is 50 kHz above the frequency you typed, so the tuner’s DC spike stays off the carrier. The waterfall is 2 MHz wide and centered on your frequency. The white line is the channel. The red line is the local oscillator. If the thin voice trace sits above the white line, raise PPM. If it sits below, lower PPM. The red line itself is the 50 kHz offset, and PPM will not move it onto the white line.

Start listen gain at 16. Raise it when the waterfall stays dark and no voice decodes. Lower it when the display turns into a bright band. The stack log under the waterfall shows AM vs FM from the IQ envelope and instantaneous frequency, plus NAC, talkgroup, source ID, vocoder PCM, and OP25 lines. A simplex channel sends no trunking control messages, so a control-channel timeout in that log is normal.

Transmit

Transmit sends the standard 1011 Hz Phase 1 test tone and latches on, the same way Receive does. Letting go does not stop it, and clicking Transmit again does not stop it. Stop is the off switch. The tone is an IMBE codeword, repeated until then. Every frame carries the NAC, talkgroup, and source ID typed here. The microphone is unused.

GNU Radio takes a few seconds to start. The tone begins after the status says transmitting, and it stays until Stop. The tuner sits 50 kHz above the channel, and the tone is shifted back down, so the DC spike stays off the carrier.

Transmit IF gain is an amplifier step, from 0 to 40 dB in steps of 8. The RF amplifier, about 11 dB, stays off. HackRF has no calibrated dBm control. With the RF amplifier off, 0 and 16 are below 0 dBm (1 milliwatt). A setting near 40 can land around 0 dBm, and the real level still changes with frequency. The board’s maximum from 10 MHz to 2170 MHz is about 5 to 15 dBm, which takes the RF amplifier on and IF gain at 47. This panel never does that. On the bench, use 0 or 16, with the radios close or a dummy load fitted.

The other radio lights and stays quiet

  • Match the frequency. A receive light can come from carrier energy before the voice frames decode.
  • Match the NAC. $F7E on that radio accepts any NAC. Typing F7E here transmits F7E, and a radio set to 293 will refuse it. Type F7E here when you want this receiver to accept every NAC.
  • Leave encryption off on that radio. These frames are clear, algorithm 80 hex.
  • Selective unmute also requires this talkgroup. Normal unmute follows the NAC and ignores the talkgroup.
  • The source ID is the sending unit. A group call plays when the NAC matches, even when this ID is different from the receiving radio.
  • If the light is on and the speaker is quiet at transmit IF gain 0, try 32 with the radios close together.
